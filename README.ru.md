# Ampulse

*ampoule + pulse* — «ампула + пульс». Офлайн-приложение для телефона: учёт таблеток, уколов и давления —
для себя, близкого человека или питомца. [English](README.md)

**Состояние:** макет интерфейса (49 экранов, русский и английский, светлая и тёмная тема). Кода
приложения пока нет.

## Идеи

- **Полностью без интернета.** Назначения распознаются на телефоне: правила, справочник лекарств,
  распознавание фото и речи.
- **Назначение → план.** Вставьте текст, сфотографируйте или продиктуйте — приложение разложит курс по
  режиму дня и спросит, чего не хватает.
- **Безопасность прежде всего.** Защита от двойной дозы, укол пошагово с отсчётом, экстренная карта на
  экране блокировки. Дозы приложение не меняет.
- **Близкие без облака.** SMS о пропуске, передача данных по QR, когда вы рядом, PDF-отчёт врачу.
- **И ещё:** ротация мест укола, запас и сроки годности, давление со своей клавиатурой, питомцы.
