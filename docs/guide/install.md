# Как поставить Ampulse

Ampulse раздаётся файлом APK из [GitHub Releases](https://github.com/AgitAngst/Ampulse/releases). Нужен
телефон с Android 10 или новее. Магазинов (RuStore, Google Play) пока нет.

## Установка

1. Откройте страницу [Releases](https://github.com/AgitAngst/Ampulse/releases) на телефоне и в самом новом
   выпуске скачайте файл `ampulse-X.Y.Z-android.apk` (вместо `X.Y.Z` — номер версии). Выпуски с пометкой
   «Pre-release» — пробные, берите их, только если знаете зачем.
2. Откройте скачанный файл (из уведомления браузера или из приложения «Файлы»).
3. Android спросит разрешение «Установка неизвестных приложений» для того приложения, из которого вы
   открыли файл (браузер или «Файлы»). Включите его для этого приложения, вернитесь назад и нажмите
   «Установить». Разрешение нужно только для этого приложения и только чтобы поставить APK; потом его можно
   выключить.
4. Откройте Ampulse.

## Проверить файл (по желанию)

В каждом выпуске лежит `SHA256SUMS` — строка `<сумма>  ampulse-X.Y.Z-android.apk`. Если сумма скачанного
файла совпала со строкой — файл целый и не подменён по дороге. На ПК:

```powershell
Get-FileHash .\ampulse-X.Y.Z-android.apk -Algorithm SHA256
```

Значение `Hash` должно совпасть со строкой в `SHA256SUMS` (регистр букв не важен).

## Обновления

Обновлять вручную не нужно: приложение само проверяет, не вышла ли версия новее.

- **Включено по умолчанию.** При каждом запуске приложение один раз спрашивает у GitHub, нет ли выпуска новее.
  Если есть — над содержимым появляется баннер: «Обновить», «Что нового», «Позже», «Пропустить эту версию».
- **Что уходит в сеть** — только этот запрос к GitHub. Ваши данные (лекарства, расписание, записи) приложение
  не отправляет никуда: оно работает без интернета.
- **Выключить:** «Настройки» → «Обновления» → «Проверять обновления». Проверить вручную — «Настройки» →
  «О программе» → «Проверить».
- **Пробные версии** предлагаются, только если включить «Предлагать пред-выпуски» (по умолчанию выключено).
- «Обновить» скачивает APK, сверяет его сумму с `SHA256SUMS` выпуска и передаёт системе — Android покажет
  своё окно подтверждения установки. Если разрешения «Установка неизвестных приложений» для Ampulse нет,
  приложение объяснит, зачем оно нужно, и откроет его настройку.
- Новая версия ставится поверх старой, данные сохраняются. Обновление встанет, только если APK подписан тем
  же ключом, что и установленный, — поэтому ставьте Ampulse только из GitHub Releases этого репозитория.
