# Ampulse — документация

Версия: 0.2.0 — макет интерфейса и каркас приложения для Android.

Это документация того, что есть сейчас. Замысел и план — [SPEC.md](../SPEC.md), заметки для следующей
сессии — [HANDOFF.md](../HANDOFF.md).

## Что есть

- **Макет** — 49 экранов на холсте claude.ai, на русском и английском, в светлой и тёмной теме. Выгрузка
  холста — [mockup/](../mockup/README.md).
- **Каркас приложения** (Android 10+, Kotlin + Jetpack Compose, пакет `io.github.agitangst.ampulse`):
  - нижняя навигация «Сегодня», «История», «Аптечка», «Близкие»; пока данных нет, на каждой вкладке —
    пустое состояние со своим пояснением;
  - «Настройки» (значок в шапке «Сегодня»): «Оформление» — тема («Как в системе», «Светлая», «Тёмная») и
    язык («Как в системе», «Русский», «English»), применяются сразу; «Обновления»; «О программе» — версия,
    номер сборки, кнопка «Проверить», ссылка на код;
  - обновление из GitHub: при запуске приложение спрашивает у GitHub, нет ли выпуска новее, и показывает
    баннер «Вышла vX · Обновить · Что нового · Позже · Пропустить эту версию». Проверку можно выключить
    («Проверять обновления»).
- Лекарств, расписания и напоминаний ещё нет — это этап 0.3 ([SPEC.md](../SPEC.md), «Этапы кода»).
- Готового APK пока нет: он появится в [GitHub Releases](https://github.com/AgitAngst/Ampulse/releases) с
  первым выпуском. Как поставить — [guide/install.md](guide/install.md).
