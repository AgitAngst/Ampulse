# Сборки для RuStore и Google Play

С версии 0.9.0. Общие правила — `anvil/docs/ANDROID.md`, разделы 2, 4 и 5.

## Чем сборки отличаются

| | `github` | `rustore` | `play` |
|---|---|---|---|
| Файл | APK в GitHub Releases | APK | AAB (языки не делятся: `bundle.language.enableSplit = false`) |
| Обновление | своё — из GitHub (`anvil-update`) | магазин | магазин |
| Сеть | проверка и скачивание обновлений | нет (`INTERNET` снят в `src/rustore/AndroidManifest.xml`) | нет (снят в `src/play/AndroidManifest.xml`) |
| SMS близким | уходит сама (`SEND_SMS`) | уведомление с готовым сообщением, «Отправить» — человек | так же |
| Напоминание на весь экран | есть | есть | нет (`USE_FULL_SCREEN_INTENT` снят): важное — обычным уведомлением с повтором |

Код: что зависит от магазина — объект `Store` (`src/github/…/Store.kt` и общий для магазинов `src/stores/…/Store.kt`,
подключён к `rustore` и `play` в `app/build.gradle.kts`). SMS из фона — `reminders/SmsOut.kt` (`Store.SILENT_SMS`).
Номер версии и `versionCode` у всех сборок одинаковые; ключ подписи — один на все (§4).

## Как собрать

На ПК, с ключом (`keystore.properties` или переменные `AMPULSE_*`, см. [development.md](development.md)):

```
./gradlew :app:assembleRustoreRelease :app:bundlePlayRelease --max-workers=2
```

Файлы: `app/build/outputs/apk/rustore/release/*.apk`, `app/build/outputs/bundle/playRelease/*.aab`.

На GitHub: Actions → Android → Run workflow, галочка «stores» — подписанные `ampulse-X.Y.Z-rustore.apk` и
`ampulse-X.Y.Z-play.aab` с `SHA256SUMS` артефактом `ampulse-store-builds` (14 дней). В GitHub Release они не идут.
Без галочки кнопка только проверяет, что сборки магазинов собираются (отладочные).

## RuStore

1. Аккаунт разработчика в консоли RuStore (владелец).
2. Новое приложение: пакет `io.github.agitangst.ampulse`, категория «Здоровье» / «Медицина», описание на русском,
   снимки экранов — только с выдуманными данными (демо-профиль), значок.
3. Политика конфиденциальности — ссылка на [docs/privacy.md](../privacy.md) в репозитории.
4. Загрузить подписанный APK из `rustore`. Разрешения объяснить в описании: уведомления и будильники — напоминания,
   камера — сканер и фото рецепта, микрофон — диктовка, Bluetooth — тонометр.

## Google Play

1. Аккаунт разработчика (владелец). У нового личного аккаунта Play требует закрытого тестирования перед выпуском в
   продакшен — число тестировщиков и срок смотреть в консоли.
2. «Подпись приложений Google Play»: загрузить **свой** ключ (тот же, что для GitHub и RuStore), а не брать выданный
   Google — иначе версии из разных мест не обновляют друг друга.
3. Загрузить AAB из `play` (`targetSdk` 37).
4. Анкеты в консоли:
   - **Безопасность данных:** данные не собираются и не передаются разработчику; хранятся на устройстве; SMS близким —
     по выбору пользователя, через приложение сообщений; сети нет.
   - **Приложения о здоровье:** да — напоминания о лекарствах, дневник давления; не медицинское изделие, диагнозов не
     ставит, дозы не меняет.
   - **Точные будильники** (`SCHEDULE_EXACT_ALARM`): напоминания о приёме лекарств в назначенное время; человек даёт
     разрешение сам, без него — неточный будильник.
   - **Политика конфиденциальности** — ссылка на [docs/privacy.md](../privacy.md).
   - Если владелец решит вернуть напоминание на весь экран в `play` — объявить `USE_FULL_SCREEN_INTENT` в консоли
     (Play оставляет его будильникам и звонилкам) и убрать `tools:node="remove"` из `src/play/AndroidManifest.xml`.
5. Снимки экранов и описание — ru и en, только выдуманные данные.
