# Spec Delta

## Purpose

Назначение врача превращается в план приёма на телефоне, без сети и без ручного ввода каждого лекарства. Дозы
приложение не меняет: только раскладывает то, что написал врач.

## ADDED Requirements

### Requirement: Sources
Разбор SHALL принимать текст (ввод, файл, «Поделиться» из другого приложения), фото (распознавание на телефоне,
русский и английский) и голос. Распознанный текст MUST показываться для правки до разбора.

#### Scenario: Shared message
- **WHEN** сообщение врача из мессенджера отправили в Ampulse через «Поделиться»
- **THEN** открывается разбор с этим текстом

### Requirement: Review
Каждая строка назначения SHALL стать карточкой: найденное в тексте — сплошная рамка, додуманное — пунктир; нет
частоты — вопрос «сколько раз в день», без ответа сохранить нельзя. Лекарство с тем же названием, что уже в списке,
MUST сохраняться как изменение его схемы, а не второе лекарство.

#### Scenario: Missing frequency
- **WHEN** в строке «Мексидол 2 мл в/м, 10 дней» нет частоты
- **THEN** на карточке вопрос «Сколько раз в день?», «Сохранить» недоступно до ответа

### Requirement: Plan
План SHALL ставить время приёмов по режиму дня человека (подъём, завтрак, обед, ужин, сон) с учётом еды и
подсказок («на ночь», «утром»), показывать срок курса, ступени отмены и сколько купить на курс.

#### Scenario: Before meals
- **WHEN** «2 раза в день до еды», завтрак 7:30, ужин 19:00
- **THEN** приёмы в 7:00 и 18:30
