# Proposal

## Why

Этап 0.5 (SPEC.md): назначение врача → готовый план без ручного ввода (макет, экраны 7–9). Решение владельца
29.10.2026: этапы подряд, между ними — пуш.

## What Changes

- Разбор назначения: текст (вставить, из файла, из «Поделиться» другого приложения), фото рецепта (распознавание
  текста на телефоне), голос (распознавание речи телефона). Русский и английский, без сети.
- Проверка разбора: строка — карточка; что взято из текста — сплошная рамка, что додумано — пунктир; чего не хватает
  (сколько раз в день) — вопрос; совпадение с лекарством в списке — «изменение дозы», а не новое лекарство.
- Готовый план: время приёмов по режиму дня, сроки курсов, ступени отмены, сколько купить; «Сохранить» — лекарства и
  схемы в базу.
- «Настройки → Режим дня»: подъём, завтрак, обед, ужин, сон.
- Версия 0.5.0.
