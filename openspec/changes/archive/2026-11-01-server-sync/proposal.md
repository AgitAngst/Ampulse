## Why

Владелец (29.10.2026) согласовал подключить приложение к своему серверу Ampulse — «зеркалу»: телефон сам
выкладывает на сервер профили, лекарства и приёмы, а сервер показывает их другим (страница просмотра, другие телефоны) и
шлёт напоминания и сообщения о пропуске. Приложение остаётся полностью офлайновым по умолчанию; сервер необязателен.
Сервер готов (его API — раздел «Зеркало» в описании API сервера, версия 0.7); приложение к нему не было подключено.

## What Changes

- Экран **«Сервер»** (Настройки → «Сервер»): адрес, логин, пароль; «Войти» и «Создать аккаунт»; после входа — состояние
  выгрузки, «Отправить сейчас», «Выйти», «Выйти и стереть копию на сервере». Только сборка `github`.
- **Одностороннее зеркало:** с телефона на сервер, ничего не скачивается. Выключено, пока человек не вошёл.
- Выкладываются профили (в т. ч. «Я»), лекарства и приёмы окна `[сегодня − 30 дней, сегодня + 14 дней]`: плановые
  (схемы раскладываются в конкретные времена, с отметками «принято»/«пропущено») и внеплановые («по необходимости»,
  лишние). Не выкладываются: аптечка и упаковки, давление, близкие, экстренная карта, место укола, количество, правила схем.
- **Идентификаторы** детерминированные и необратимые (SHA-256 от случайной соли телефона, вида и локальных чисел); новых
  таблиц Room и миграции базы нет.
- **Состояние выгрузки** — файл в `filesDir` (вид → id → отпечаток): уходит только новое и изменённое, пропавшее удаляется.
- **Запуск:** вручную, при открытии приложения и через ~30 секунд после изменения данных (одна отложенная задача). Без WorkManager.
- Сеть — `HttpURLConnection` и `org.json`; HTTPS обязателен; пароль не хранится, токен — в приватных `SharedPreferences`.
- Документы: `docs/dev/server-sync.md`, `docs/privacy.md` (ru+en), `docs/guide/usage.md`, `docs/ui-guideline.md`, `SPEC.md`,
  `docs/README.md`, `HANDOFF.md`.

## Non-goals

- Приём данных с сервера (синхронизация «туда и обратно»), правка данных на сервере, конфликты.
- Сборки RuStore и Play: сети в них нет и не будет (экран «Сервер» и код выгрузки там не работают).
- Фоновая выгрузка при закрытом приложении (WorkManager) и повторные попытки по расписанию.
- Выкладывание давления, аптечки, близких и экстренной карты; правил схем (на сервер уходит результат).
- Проверка сертификата по отпечатку: сервер стоит за обычным обратным прокси с настоящим сертификатом.

## Impact

`app`: пакет `sync/` (идентификаторы, модель и построение выгрузки, состояние и разница, клиент, движок, `ServerSync`),
`ui/ServerScreen.kt`, `Routes.kt`, `SettingsScreen.kt`, `AppGraph.kt`, `data/` (запросы только для чтения, без изменения
схемы), `Store` (флаг `SERVER_SYNC`), манифест `github` (`INTERNET` явно), правила переноса (`data_extraction_rules.xml`),
строки RU/EN. Тестовая зависимость `org.json:json` (в `android.jar` методы-заглушки). Репозиторий публичный: данные в
тестах и примерах — выдуманные.
