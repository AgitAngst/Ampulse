# Design

## Context

Знак: ампула с горлышком и плечами, тело 380 единиц шириной на плитке 1024. Стекло — `#E8E8EA`, жидкость —
акцент `#4FBFB0`, плитка `#2A2A2E`. Верхний край жидкости — ломаная пульса: точки
`(322,L) (400,L) (474,L−150·a) (552,L+130·a) (612,L) (702,L)`, где `L` — уровень (в покое 590),
`a` — сила пика (0…1, в покое 1). Жидкость обрезана контуром ампулы. Единицы плитки; в коде
переводятся масштабом размера знака.

## Decisions

1. **Двигается только жидкость.** Уровень `L` и сила пика `a` — единственные параметры. Ампула, плитка и
   цвета неподвижны; знак не прыгает и не вращается. Так знак остаётся спокойным в медицинском
   приложении.
2. **Три сцены, как в эталоне.**
   - Запуск, 1300 мс: `L = 900 → 590` по `ease_out_cubic` за первые 70 %, затем `a` растёт 0 → 1 с
     небольшим перелётом (`ease_out_back`) за 30 %.
   - Ожидание, цикл 1600 мс: `L = 590`; `a = 0,35 + 0,65·удар`, удар: 0 → 1 за 12 % цикла
     (`ease_out_cubic`), 1 → 0 до 40 %, дальше 0 (дежурный пик 0,35, чтобы знак не «ломался» между ударами).
   - Готово, 900 мс: `L = 590 − 24·sin(π·t)`; `a = 1 + 0,25·sin(2π·t)` за первую половину (пик на миг выше
     обычного), потом 1.
3. **Где показывать (как внедрено в 0.9.2).** Запуск — при каждом открытии «О программе» (знак 48 dp в
   карточке). Ожидание — на экране отчёта врачу, пока отчёт собирается (28 dp, вместо крутилки). Готово —
   на том же экране, когда отчёт собран (40 dp над сообщением). Обычные действия (отметить приём, записать
   замер) знак не оживляют: там своя обратная связь по `docs/ui-guideline.md`. Открытие приложения
   показывает системный splash (неподвижный значок), в шапке главного экрана знака нет. Импорт плана
   сохраняется мгновенно и знак не показывает.
4. **Покой не просит кадров.** После сцены «Запуск» или «Готово» — один кадр покоя, перерисовок нет;
   «Ожидание» крутится, только пока операция идёт и экран виден.
5. **Меньше движения.** Если масштаб анимации в системе равен нулю (`ANIMATOR_DURATION_SCALE`), знак
   рисуется в покое (`L = 590`, `a = 1`), без движения.
6. **Знак — одна функция.** `MarkLiquid(level, amp)` рисует кадр; машина сцен — чистый код без Compose
   с тестами (числа кадра по времени).
7. **Значок запуска неподвижен.** Система не анимирует адаптивные значки; монохромный вариант — силуэт
   ампулы с вырезом пульса.

## Risks

- На 16 dp пик пульса в покое читается слабо; поэтому анимация только на крупных местах (28 dp и выше),
  в уведомлениях остаются `ic_stat_*`.
- Splash Android 12+ задаёт значок системой: там знак остаётся неподвижным.
