# Design

## Context

Правила Android-программ — `anvil/docs/ANDROID.md`; набор — `anvil/android` (0.2.0); вид — `docs/ui-guideline.md`,
макет — `mockup/`. Решения владельца 29.10.2026: Android, Kotlin + Compose, APK из GitHub, позже RuStore и Google
Play; пакет `io.github.agitangst.ampulse`; проверка обновлений включена; набор — подмодулем.

## Goals / Non-Goals

**Goals:** собираемый каркас с темой, языками, вкладками, настройками, обновлением; подпись и выпуск по соглашению.

**Non-Goals:** данные (Room), лекарства и расписание (этап 0.3), сборки `rustore`/`play`, свои шрифты (до разрешения
владельца — системные), значок приложения (отдельно, по `ICONS.md`; до него — простой знак-заглушка).

## Decisions

- **Подмодуль `anvil/`** на коммите набора 0.2.0; `settings.gradle.kts` — `includeBuild("anvil/android")`; модули
  набора подставляются по группе `io.github.agitangst.anvil`. Тег набора поставит владелец — тогда подмодуль
  переходит на тег.
- **Палитра Ampulse** — `AnvilPalette.light/dark(Accents.AMPULSE).copy(...)` с нейтральными цветами из
  `docs/ui-guideline.md` §3 (фон `#F4F2EC`/`#111715`, карточка, текст, рамки, внимание и т. д.).
- **Навигация** — без новой библиотеки: состояние вкладки и стек «Настройки» в `rememberSaveable`, жест «назад» —
  `BackHandler`. Navigation Compose появится, когда экранов станет больше.
- **Вход в настройки** — значок-шестерёнка в шапке «Сегодня» рядом с «+». В макете его нет — доска для холста
  предлагается отдельно.
- **Подпись** — `keystore.properties` (в `.gitignore`) или переменные окружения `AMPULSE_KEYSTORE*`; ключ создаёт
  владелец скриптом `scripts/new-keystore.ps1`. Выпускная сборка без ключа падает с понятной ошибкой.
- **Workflow** — `.github/workflows/android.yml` по скилу `github-ci`: `workflow_dispatch` и тег `v*`, Ubuntu, JDK 21,
  `submodules: true`, `fetch-depth: 0`, потолок времени; на тег — подписанный APK, `SHA256SUMS`, Release.

## Risks / Trade-offs

- [Подмодуль на коммите, а не на теге] → переход на тег, когда владелец его поставит; записано в HANDOFF.
- [Системные шрифты вместо Literata и Onest] → шрифты — отдельным шагом с разрешения (файлы с Google Fonts, OFL).
- [Нет ключа выпуска] → выпуск невозможен, пока владелец не создаст ключ и не положит секреты; отладочная сборка и
  CI по кнопке работают без него.
