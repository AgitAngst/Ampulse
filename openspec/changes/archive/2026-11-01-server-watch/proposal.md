## Why

Владелец (29.10.2026): хочет смотреть таблетки и приёмы других людей и животных, в том числе в приложении, а не только на
странице сервера. Сервер уже умеет отдавать чужие профили (роли «опекун» и «наблюдатель», приглашения по коду,
`GET /api/v1/sync`); приложение сейчас только выкладывает свои данные (`server-sync`).

Решено: **сначала макет** (холст, экраны 62–77, сделан 29.10.2026). Это изменение — описание того, что будет делать код
после утверждения макета; кода пока нет.

## What Changes

- Строка «Профили других людей» в подключённом экране «Сервер» → экран-список: профили, которыми поделились, с ролью и временем
  обновления, «Убрать» с подтверждением; «Ввести код приглашения» → экран ввода кода (`POST /api/v1/invites/accept`).
- «Сегодня» чужого профиля: переключатель профилей в верхнем поле («Я», чужие «по серверу»); те же кольцо и строки, но только
  просмотр (чип состояния вместо кнопки отметки); плашка «Только просмотр · обновлено в …»; без связи — плашка внимания и
  последние данные.
- Данные: приложение забирает чужие профили по `GET /api/v1/sync` (журнал по номеру; новый профиль — `since=0&profile=<id>`;
  `resync` — начать с нуля) и хранит в JSON-файле кэша в `filesDir` (не Room, без миграций; решение исполнителя
  29.10.2026). Опрос — при открытии приложения, при входе на экраны чужих профилей и после «Отправить сейчас».
- Возврат убранного профиля (правка 31.10.2026, по находке проверки на телефоне): код приглашения, валидный при живом
  доступе, сервер отвечает конфликтом — приложение снимает пометку «убран» со всех и обновлением возвращает профили с
  живым доступом; зритель больше не зависит от владельца.
- Только сборка `github`, как и «Сервер».

## Non-goals (первая версия)

- Отметки приёмов с телефона над чужим профилем (роль «опекун» это позволяет на сервере — потом, через `POST /api/v1/sync/push`).
- Уведомления на телефоне о чужих приёмах (их шлёт сервер по ntfy, Telegram и Amber).
- Фоновый опрос при закрытом приложении.
- Создание приглашений в приложении (их создаёт владелец на странице сервера).
