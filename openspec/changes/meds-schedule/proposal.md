# Proposal

## Why

Этап 0.3 по плану (SPEC.md, «Этапы кода»): каркас 0.2 есть, теперь главное — лекарства, расписание, лента «Сегодня»,
напоминания и защита от двойной дозы (макет, экраны 1, 2, 4, 6, 10, 11, 15). Решение владельца 29.10.2026: делать
этапы подряд, между ними — пуш.

## What Changes

- Данные на телефоне (Room): лекарства, схемы, отметки; схемы — каждый день, дни недели, раз в N дней, циклы,
  ступени, «по необходимости», пауза.
- «Сегодня»: лента приёмов по времени, кольцо дня, отметка одним касанием, пропуск с причиной, защита от двойной
  дозы, лишний приём для врача.
- «Аптечка»: список лекарств; новое лекарство и правка со схемой; «по необходимости» — таймер и лимит.
- «История»: календарь соблюдения и отметки по дням.
- Напоминания: будильники системы, уведомление с «Принять» и «Отложить», для важных — на весь экран с повтором;
  после перезагрузки — заново; раздел «Напоминания» в настройках (разрешения).
- Версия 0.3.0.
